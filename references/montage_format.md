# 混剪镜头表（混剪模式）

混剪是 1–2 分钟的快节奏片子，所有切点都卡在音乐的小节线上。用 `render_montage.py` 出片。

## 节奏怎么算

- 默认 140 BPM，一小节 = 4 拍 ≈ 1.71 秒。
- 片头默认 2 小节、片尾 3 小节（`--intro` / `--end` 可改）。
- 总时长 = (片头 + 所有镜头小节数 + 片尾) × 1.71 秒。想做 2 分钟，镜头加起来大约 65 小节；1 分钟大约 30 小节。
- 用户自己的歌：要知道它的 BPM，用 `--music 歌.mp3 --bpm 128 --music-offset 3.2`（从歌的第几秒开始，让第一拍对上片头）。不知道 BPM 就问用户，或者建议用合成配乐。

## 片头和片尾

在 `project.json` 里配：

- 片头默认是手写的 `title` 加一行 `subtitle`。填了 `route`（如 `["上海", "河内", "芽庄", "胡志明"]`）就改成路线片头：每 2 拍蹦出一个地名、卡在鼓点上，第 4 拍淡入 `date`（如 `2026.9.26 — 10.3`）。片头 2 小节正好放下 4 个地名。
- 片尾：`title` 和 `end_text` 都有时显示两行（片名在上、`end_text` 在下，如「越南 / 下次见」），只有一个就显示一行。

## 列

| 列名 | 说明 |
| --- | --- |
| `片段` | 片段 ID |
| `入点` | 从原片第几秒开始，`mm:ss.xx` |
| `小节` | 占几小节。1 = 一个卡片镜头；2–3 = 重点镜头；**小于 1（如 0.5）= 全屏快切**，不显示卡片和文字，带 RGB 分离效果，适合连续快闪 |
| `小字` | 卡片上方的一行英文斜体小字（中文也行），如 `nine twenty-seven` |
| `大标题` | 卡片下方的大字，英文用粗黑体、中文用粗体，自动缩小到放得下 |
| `副标题` | 大标题下面的一行中文 |
| `标记` | 可组合：`v` = 混入这个镜头的原声（音乐自动压到 30%）；`f` = 切入时白闪；`r` = 卡片放右边（默认左边，左右交替更有节奏） |

## 编排经验

- **左右交替**：卡片一左一右，`r` 隔一个加一个。
- **白闪用在段落开始**：每一章第一个镜头、音乐 drop 的那一下加 `f`。
- **原声镜头别太多**：一支 2 分钟混剪 3–5 个 `v` 就够了，选最有梗的那句话，入点卡在这句话开始前 0.3 秒左右。
- **快切连发**：3–4 个 0.5 小节的全屏镜头连着放，用在情绪高点前后。
- **大标题要短**：英文 1–3 个词（`FLY HIGH`、`OVER MY HEAD`），中文 2–6 个字（「下次不来了」）。是给画面起名字，不是写说明。
- **副标题可以用原话**：「我还有点恐高」比「他说他恐高」好。
- **先出预览**：`--preview 序号` 只渲染一个镜头存成三张截图，几秒钟就能看出构图和文字是否合适，不要每改一处就整片重渲。
