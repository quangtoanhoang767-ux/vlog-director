# 剪辑表格式（长片模式）

剪辑表是一个 CSV 文件，放在 `edit/剪辑表_v1.csv`、`剪辑表_v2.csv`……每改一版存一个新文件，旧的不删，方便对比和回退。用 `render_long.py` 出片。

**用 UTF-8 带 BOM 保存**（Python 用 `encoding="utf-8-sig"`），这样用户双击用 Excel 打开也不乱码。

## 列

| 列名 | 必填 | 说明 |
| --- | --- | --- |
| `#` | 是 | 序号 |
| `段落` | 否 | 章节名，如「开头」「第一章 河内」，只给人看 |
| `片段` | 是 | 片段 ID（原片文件名去掉扩展名）。字卡、黑场写 `—` |
| `入点` / `出点` | 是 | `mm:ss.xx`。字卡、黑场不填，改填 `时长` |
| `时长` | 否 | 只有字卡、黑场用，单位秒 |
| `声音` | 是 | 见下 |
| `音乐` | 否 | `verse` / `chorus` / `light`，只在用合成配乐时有用；不填就按位置自动选 |
| `字幕` | 否 | 见下 |
| `剪辑理由` | 是 | 为什么用这个镜头。**给用户看的**，用户靠这一栏判断你在想什么 |

## 声音列

| 写法 | 效果 |
| --- | --- |
| `同期声` | 用现场声，配乐自动压低（有人说话时 -34 dBFS） |
| `BGM` | 现场声压到 30% 当环境音，配乐正常 |
| `静音` | 不要现场声 |
| `BGM停` | 这个镜头最后 1.3 秒音乐留白（比如跳水前那一下安静） |
| `BGM全停` | 这个镜头完全没有音乐（比如有人在放歌、需要听清某句话） |
| `黑场` | 画面变黑 |

可以组合：`同期声 BGM停`。

## 字幕列

- 多句对白用 `｜`（全角竖线）分隔：`你接一下｜放他走吧，要不然他累`。脚本会自动去转写里找每句的时间，对齐到说话那一刻。
- `【字卡】文字`：画面上方的说明字，显示 3 秒。
- `【强调字】文字`：画面中间的黄色大字，用来点题（如「强劲的音乐」）。
- `【片名】`：片名大字，文字取 project.json 的 `title`，也可以写 `【片名】自定义片名`。
- 字卡行（片段写 `—`）的字幕就是黑底上的字。

**字幕只用转写核实过的原话**，听不清的宁可不加。

## 例子

```csv
#,段落,片段,入点,出点,时长,声音,音乐,字幕,剪辑理由
1,开头,DJI_0053,02:04.0,02:13.0,,同期声,,很棒很棒很棒｜刚好拍到！,开场：火车从相机头顶压过，画面奇观 + 一句欢呼
2,开头,—,,,2.5,黑场,,【片名】,片名
3,第一章 河内,DJI_0007,00:00.0,00:23.0,,同期声,verse,九月二十七号成功会师｜下次再也不来了,四人第一次同框；埋下『下次不来了』的伏笔
4,第一章 河内,DJI_0010,00:08.0,00:14.0,,BGM,verse,,湖边空镜，章节呼吸
```
